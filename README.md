# Student Management Node API

This is the backend API of the Student Management System built with Node.js and Express.

## Technologies Used

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT
* bcrypt

## Features

* User Registration
* User Login
* Password Hashing
* JWT Authentication
* User and Admin roles
* Student CRUD APIs
* Protected APIs
* User can only update and delete their own students
* Admin can manage all students

## Testing

The APIs were tested using Thunder Client.
